#+title: picard-mode

Emacs major modes for MusicBrainz Picard Tagger Script.

Picard's file naming and tagging scripts grow into deeply nested =$if(...)=
calls, where a misspelled function or a missing parenthesis is easy to
write and hard to spot.  picard-mode edits those scripts in Emacs.

It highlights functions, variables, escapes and known tags, treats
=$noop(...)= as a comment for the usual comment commands, and indents nested
calls with tabs, one per level.  Flymake reports unknown functions, wrong
argument counts and unbalanced =%= or parentheses.  Eldoc shows the
signature and documentation of the function or tag at point.  Completion
offers function names after =$= and tag names inside =%...%=, from the
package's catalogue of Picard built-ins.

* Install

Requires Emacs 27.1.  The Tree-sitter variant, =picard-ts-mode=, needs Emacs
29.1 and the [[https://codeberg.org/useless-utils/tree-sitter-taggerscript][taggerscript grammar]].

#+begin_src elisp
(package-vc-install "https://github.com/11xx/picard-mode") ; Emacs 29+
#+end_src

With Elpaca, =(elpaca (picard-mode :host github :repo "11xx/picard-mode"))=;
with straight.el, =(straight-use-package '(picard-mode :host github :repo "11xx/picard-mode"))=.

* Use

Files ending in =.picard=, =.pts= or =.ptsp= open in the mode, and =C-c C-d=
shows the documentation and diagnostics at point in a help buffer.

For =picard-ts-mode=, =M-x picard-ts-mode-install-grammar= clones and
compiles the grammar, which needs =git= and a C compiler.  On Emacs 29 and
later the package's autoloads open these files in =picard-ts-mode=, which
has no highlighting or indentation until the grammar is installed.
